# 利用ガイド

## 画面とメニュー

| 画面 | ルート | 内容 |
| --- | --- | --- |
| ホーム | `/` | 学習対象と補助機能への入口 |
| 詰め将棋 | `/tsume` | 難易度・タグ選択、ランダム出題、ヒント、解説、お気に入り |
| タイムアタック | `/time-attack` | 5問／10問の連続出題、時間・正解・ミスの記録 |
| 定跡学習 | `/openings`, `/openings/:id` | 戦型・手順選択と盤上学習 |
| 次の一手 | `/next-move`, `/next-move/:id` | 専用DBの局面から一手を考える |
| 復習 | `/review` | 間違えた詰め将棋、お気に入り、次の一手の復習 |
| 学習記録 | `/history` | 正答率、最近の解答、タイムアタック、次の一手の集計 |
| 問題作成 | `/problem-editor` | 詰め将棋の作成・編集・削除 |
| 表示設定 | `/settings` | 駒・盤テーマと組み合わせプリセット |
| データ出典 | `/licenses` | 取り込んだデータと画像素材の出典・ライセンス |

デスクトップでは上部ナビゲーションに主要機能と補助機能を表示します。モバイルでは「ホーム」「詰め将棋」「定跡」「次の一手」「その他」の下部ナビゲーションになり、「その他」に復習、学習記録、問題作成、設定、データ出典があります。旧URL `/openings?mode=next-move` と `/openings/next-move/:id` は現在の次の一手画面へ転送されます。

## 盤の共通操作

- 盤上の駒は「駒をクリックして移動先をクリック」またはドラッグで動かせます。
- 持ち駒は駒台で選択し、打つ升をクリックします。
- 成れる手では「成る／成らず」を選択します。成りが必須なら自動で成ります。
- 利用できる画面では「盤面反転」「一手戻る」「最初に戻る」を使えます。
- 表示設定では文字駒、3種類の画像駒、標準盤、3種類の画像盤を個別選択でき、「画像・明るい」「伝統」「ダーク」のプリセットもあります。設定はブラウザごとのローカルストレージに保存されます。

## 詰め将棋

1. 手数とタグで問題を絞り、問題またはランダム出題を選びます。
2. 攻め方の手を盤上で指します。3手詰・5手詰では正解後に登録済みの玉方応手が自動実行されます。
3. 必要に応じてヒント、答え、解説を確認し、お気に入りに登録します。

正解判定は登録手順との一致です。別の詰み筋が実在しても登録されていなければ正解になりません。玉方は探索した最善手ではなく登録応手を指します。移動候補表示はtsshogiの合法手判定に従いますが、打ち歩詰め禁止は候補ハイライトには反映されません。タイムアタックで選択問題数に問題が足りない場合は同じ問題を循環利用します。

## 定跡学習

定跡一覧は次のデータを同じ入口から扱います。

- フロントエンドに同梱された固定手順
- 通常DBに初回投入される定跡seedとcanonical Wikipedia artifact
- SFEN/USIから通常DBへ取り込んだ手順

戦型を選んで手順を開き、盤上で表示中の登録手を指します。分岐局面では表示された候補のいずれも受け付けます。本線はデータで `is_main` として明示された手を優先し、単なる候補配列の先頭という意味ではありません。

- 「この変化を見る」で現在局面の分岐を選択
- 「通過した分岐」で過去の分岐点へ戻して別の進行へ切り替え
- 「本線を一手進む」「ここから本線を最後まで再生」で、選択済みの変化を保ちながら以後の本線を再生
- 「直前の分岐点へ戻る」で分岐点へ移動
- 「この定跡の変化」の一覧から任意の収録手へ移動し、必要ならその分岐点から本線へ切り替え

画面の「本線のヒント」「現在の本線手」は上記の明示された本線を示します。収録手順の終了は、その戦法の研究や変化をすべて網羅したという意味ではありません。特にWikipedia由来データは、出典で確認し監査した範囲だけを収録します。画面の出典、セクション、取得日、coverage表示を確認してください。

## 次の一手

次の一手は `next_move.db` の `learning_samples` と候補手を必要とします。これらの学習サンプルは次の一手画面の出題データであり、定跡一覧へ通常表示される手順ではありません。戦型と問題を選ぶか、ランダム／未挑戦優先／復習対象から出題します。着手前は答えを隠し、ヒントは駒種、移動先の順に表示します。

合法手を指した後の表示は「将棋としての絶対的な正誤」ではなく、取り込み元DB内の候補との照合です。

- **最有力候補**: 登録順位1位
- **有力候補**: 登録順位2〜3位
- **その他の登録候補**: 登録順位4位以下
- **未登録**: 合法手だが、その局面の登録候補にはない手（手の価値を完全に否定する意味ではありません）

評価値は取り込み元の数値をそのまま表示し、有利・不利の向きや単位を推測しません。最上位候補との差は絶対差の参考値です。解答後は候補、PV、出典・ライセンスを比較できます。お気に入りとサーバー側sequential cursorは未対応で、一覧表示にも件数上限があります。

専用DBが未配置、不正、必須項目不足、またはサンプル0件なら次の一手画面に復旧案内が出ます。他の画面は引き続き利用できます。

## 問題作成

1. 配置駒と編集モード（配置、移動、削除）を選んで局面を作ります。
2. 持ち駒と手番を設定し、盤面からSFENを生成します。既存SFENを盤へ反映することもできます。
3. タイトル、手数、難易度、タグ、解説を入力します。
4. 「盤面で解法手順を記録」で指すか、USI列を直接編集します。
5. 「検証して保存」でブラウザとサーバーの検証後に保存します。

保存内容は通常DBに入ります。編集・削除は元に戻せないため、重要な問題を扱う前に [DBのバックアップ](data-management.md#バックアップ差し替え復旧) を取得してください。
